# Product Overview

## Screen Translator

A cross-platform desktop application that captures text from any screen area and translates it between multiple languages using Google's Gemini AI.

### Core Functionality
- **Screen Capture**: Multi-monitor support with overlay selection interface
- **OCR Text Extraction**: AI-powered text recognition from captured images
- **Translation**: Support for 11 languages with bidirectional translation
- **System Integration**: Global hotkeys, system tray, and clipboard integration

### Key Features
- Real-time screen capture with visual selection
- Editable text extraction results
- Manual translation control (no auto-translate)
- Persistent settings with electron-store
- Cross-platform support (macOS, Windows, Linux)
- High-DPI display support
- macOS screen recording permission handling

### Target Users
- Users working with foreign language content
- Researchers and students
- Business professionals with international content
- Anyone needing quick visual text translation

### Supported Languages
English, Russian, Ukrainian, Spanish, French, German, Italian, Portuguese, Chinese (Simplified), Japanese, Korean, plus Auto-detect for source language.
